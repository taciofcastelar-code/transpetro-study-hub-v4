# Transpetro Study Hub V6 Adaptive

Pacote para upload manual no GitHub Pages.

Envie os arquivos e pastas de dentro deste ZIP para a raiz do repositório. O index.html precisa ficar na raiz.

Estrutura modular: index.html, css/app.css, js/app.js, data/questions.js, manifest.webmanifest e service-worker.js.

A V6 preserva o banco e a interface existente e adiciona uma camada modular para histórico de tentativas, domínio conceitual, seleção adaptativa, múltiplos temas, identificação de justificativas fracas e exportação de progresso.

Importante: revisão normativa e melhoria de justificativas continuam dependendo de validação questão por questão; o sistema não inventa base normativa.
