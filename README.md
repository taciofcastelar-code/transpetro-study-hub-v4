# Transpetro Study Hub V4 PWA

Aplicativo web progressivo para estudo do concurso Transpetro — Enfermeiro do Trabalho / CESGRANRIO.

Esta edição usa estrutura plana: todos os arquivos devem ser enviados juntos para a raiz do repositório.

## Recursos
- 942 itens importados / 923 questões únicas
- treino por área, fonte, dificuldade e quantidade
- simulados na ordem original
- correção comentada
- favoritas e caderno de erros
- progresso salvo no navegador
- migração automática do progresso salvo na V3
- funcionamento offline após a primeira abertura
- instalável em Android, iPhone/iPad e desktop

## Publicação no GitHub Pages
1. Envie todos os arquivos deste projeto para a raiz do repositório.
2. No GitHub: Settings → Pages.
3. Em Build and deployment, escolha Deploy from a branch.
4. Branch: `main`, pasta `/ (root)`.
5. Salve.
6. Abra a URL do GitHub Pages fornecida pelo GitHub.

## Instalação
- Android/Chrome: abra a URL e toque em Instalar/Adicionar à tela inicial.
- iPhone/Safari: Compartilhar → Adicionar à Tela de Início.
- Computador/Chrome ou Edge: use o ícone de instalação na barra de endereços.

Os dados de progresso ficam armazenados localmente em cada dispositivo.
